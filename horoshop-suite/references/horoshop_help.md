## Версии Хорошопа

| Версия | Что важно |
|---|---|
| **v3** | Базовая. Нет: `installments_payment`, `monobank_installments_payment`, `unit_of_measurement`, `wholesale_prices`, `icons/export`. При попытке через API → код 11. |
| **v4** | Текущая. Все поля доступны. `icons/export` работает. |
| **v4.7+** | В `orders/get` товары имеют `type` (`gift`, `gift_parent`, `set_main`, `set_item`). |

При оркестрации suite автоматически пытается выполнить v4-фичи; если магазин на v3 — соответствующие шаги вернут код 11 и будут отмечены в SUITE_REPORT.md как «требует v4 / включить в шаблоне даних».

## Принципы суммарного отчёта

Когда `run_suite.py` собирает `SUITE_REPORT.md`, он должен:

1. **Цитировать справку** для каждой рекомендации (со ссылкой на нужный URL `help.horoshop.ua`)
2. **Разделять**:
   - 🟢 Что починили через API
   - 🟡 Что нужно сделать вручную в админке (с указанием раздела)
   - ❌ Что нельзя ни через API ни через админку (это уровень платформы — robots, sitemap, микроразметка)
3. **Не предлагать невозможное** — если фича только через поддержку Хорошопа (типа кастомизации robots.txt) — указать «обращаться в support»

## Раздел админки → задача (быстрый поиск)

| Где в админке | Какие задачи | Какой скилл это покрывает |
|---|---|---|
| Налаштування → Система → Каталог → Шаблон даних | Включение полей для импорта | `horoshop-full-audit` фиксы могут возвращать код 11 |
| Налаштування → Користувачі | Создание API-юзера | Все скиллы (через `references/api_admin_setup.md`) |
| Маркетинг → SEO → SEO шаблоны | SEO для категорий и товаров | `horoshop-full-audit` (категорийный SEO как «то что надо в админке») |
| Маркетинг → SEO → sitemap.xml | Перегенерация sitemap | Не покрывается (платформа сама) |
| Сайт → Стикери для товарів | Создание кастомных стикеров | `horoshop-marketing-psych` (валидирует существование) |
| Сайт → Дизайн → Редактор дизайна | Стиль стикеров, темы, баннеры | `horoshop-design-extract` (читает результат) |
| Налаштування → Загальні налаштування → Логотипи | Загрузка логотипа | `horoshop-design-extract` (скачивает текущий) |
| Налаштування → Способи оплати | Подключение онлайн-оплаты, Оплата частями | `horoshop-full-audit` (включает через API когда возможно) |
| Налаштування → Способи доставки | Нова Пошта, Укрпочта | `horoshop-sales-report` (читает статистику) |
| Маркетинг → Знижки → Карта клієнта | Персональные скидки | Не через API |
| Каталог → Кольори (для фільтрів) | Группировка цветов | `horoshop-consistency` (учитывает что это отдельно от `color`) |
| Каталог → Категорія → SEO-текст | SEO-тексты категорий | `horoshop-full-audit` (только репортит, не фиксит) |

## Что находится за пределами наших скиллов

❌ **Программный РРО** (Checkbox, Vchasno Kasa) — отдельная интеграция
❌ **Брошенные корзины** (email-цепочки) — настраивается в админке
❌ **B2B / оптовые цены** — отдельный модуль (`11_B2B.md`)
❌ **Web-hooks** на события — отдельная интеграция (`02_Web-hooks.md`)
❌ **Подсказка популярных городов** при оформлении заказа

Если пользователь спросит про эти вещи — ссылаться на оригинальную справку Хорошопа: `https://help.horoshop.ua/ru/`.
