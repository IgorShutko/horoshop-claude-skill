## Логотипы

### Куда загружать
**Налаштування → Загальні налаштування → Логотипи**

### 4 варианта логотипа
| Тип | Где используется | Рекомендация |
|---|---|---|
| **Основной** | Шапка десктопа | PNG в большом разрешении (платформа сжимает) |
| **Мобильный** | Шапка мобильной версии | Горизонтальный вариант. Если логотип квадратный — лучше не загружать (будет мелкий), показывать название |
| **Футер** | Подвал сайта | Белый на прозрачном фоне |
| **Для печати** | Чеки, документы | Чёрно-белый для контраста |

### Best practice
- PNG с прозрачностью (для футера)
- SVG поддерживается, но не везде
- Загружай в большом разрешении — платформа сама масштабирует

📄 [Загрузка логотипа](https://help.horoshop.ua/ru/articles/1913435-загрузка-логотипа)

## Дизайн-система Хорошопа

### Где настраивается дизайн
**Сайт → Дизайн → Редактор дизайна**

### Настраиваемые элементы
- **Общие настройки** — основной цвет, шрифт, стиль кнопок
- **Карточки товаров** — стили стикеров, расположение цены, отображение характеристик
- **Страница товара** — структура: галерея, описание, характеристики, отзывы, кросс-сейл
- **Главная страница** — баннеры, блоки товаров, виджеты соцсетей
- **Шапка** — логотип, меню, поиск, корзина
- **Футер** — колонки, ссылки, соцсети

### Темы
- Хорошоп предоставляет ~10 готовых тем
- Каждая тема имеет свои CSS-переменные
- Кастомизация через **Сайт → Дизайн → Редактор кода** (требует знания CSS/JS)

📄 [Редактор дизайна](https://help.horoshop.ua/ru/articles/1703574-редактор-дизайна)

## Что извлекает скилл с публичной главной

### CSS-переменные
- `--primary`, `--accent`, `--background`, `--text` — основные брендовые цвета
- Хорошоп v4 темы используют CSS Custom Properties (на v3 — статичные значения в CSS)

### Цвета (frequency analysis)
- HEX (#abc, #abcdef, #abcdef88) → нормализуется в #aabbcc
- RGB(A) — `rgba(255, 0, 0, 0.5)`
- Топ-15 по частоте обычно даёт реальную палитру

### Шрифты
- `font-family` в CSS
- Часто из Google Fonts или загружены локально через `@font-face`
- Стандартные для UA-магазинов: Inter, Roboto, Open Sans, e-Ukraine, Stem

### Логотип
- Поиск `<img>` в `<header>` с классом / alt содержащим "logo"
- Fallback: `og:image` из `<meta property="og:image">`

### Favicon
- `<link rel="icon">` или `<link rel="shortcut icon">`
- Обычно `/favicon.ico` или `/favicon.png`

## Что Хорошоп позволяет извлечь, что нет

### ✅ Через публичный HTML/CSS
- Цвета, шрифты, CSS-переменные
- Логотип, favicon, OG-image
- Структура шапки (меню, поиск)
- Расположение блоков на главной

### ❌ Через публичный HTML
- Темы / стиль из админки (нужен доступ)
- CSS-кастомизации в Редакторе кода (видны на проде, но не как «настройки»)
- Подключённые внешние сервисы (видны через `<script>`, но без админ-логики)

### ✅ Через API (но не работает с дизайном)
- Каталог, заказы, страницы — есть
- Дизайн-система — НЕТ, через API не управляется

## User-Agent при парсинге

Хорошоп использует JS-challenge / WAF на некоторых магазинах. Стандартный Python-UA получает 518-байтовый JS stub.

**Рабочий UA:** `Mozilla/5.0 (Horoshop SEO Audit)` или любой современный Chrome.

## Стикеры (визуальная сторона)

### 5 предустановленных стилей в Хорошопе
- Прямоугольные с заливкой
- Округлённые с тенью
- Овальные
- Угловые (как в треугольнике)
- С градиентом

Меняется в **Сайт → Дизайн → Редактор дизайна → Карточки товаров → Стиль стикеров**.

### Кастомизация стикеров
- Текст + переменные (`{DISCOUNT_PERCENT}`, `{COUNTDOWN_INFO}`, `{PARTS}`, `{MONOBANK_PARTS}`)
- Изображение PNG (в 2× для retina) или SVG
- Цвет фона / текста
- Способ активации (см. справку по стикерам)

📄 [Стикеры в карточке товара](https://help.horoshop.ua/ru/articles/3240575-стикеры-в-карточке-товара)

| Что | Куда применить |
|---|---|
| Брендовые цвета (топ-3) | Использовать в текстах description (если делаем психологическую обвязку через `horoshop-marketing-psych`) |
| Шрифты | Презентация клиенту — «вот что у вас сейчас», аргумент для редизайна |
| Логотип | Использовать в OG-изображениях, презентациях |
| CSS-переменные | Если магазин на v4 — можно настраивать через **Сайт → Дизайн → Редактор кода** |
