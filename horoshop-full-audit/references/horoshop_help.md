## 1. API

### Авторизация
- POST `https://<DOMAIN>/api/auth/` с JSON `{"login": "...", "password": "..."}`
- Возвращает `token` длиной 32 символа
- TTL токена — **600 секунд**
- Использовать только POST (GET deprecated, может быть удалён)
- Header: `Content-Type: application/json`
- 📄 [Авторизация (API_Хорошоп/01_Авторизация.md)](https://help.horoshop.ua/ru/articles/3960898-api)

### Каталог: импорт
- `POST /api/catalog/import/` — пакетное обновление товаров
- Идентификация по `article` (артикулу)
- Лимит на батч ~50 товаров
- При ошибке поле не в шаблоне — **код 11**: «Переданный параметр не найден в шаблоне "Каталог"»
  - Включить в админке: **Налаштування → Система → Каталог → Шаблон даних**
- Системные стикеры доступны через `icons[]` (массив имён)
- 📄 [Импорт товаров (API_Хорошоп/08_Каталог.md)](https://help.horoshop.ua/ru/articles/3960898-api)

### Каталог: экспорт
- `POST /api/catalog/export/` — выгрузка с пагинацией
- Параметры: `offset`, `limit` (макс 100), `includedParams[]`, `excludedParams[]`
- `expr.parent` или `expr.parent.id` — фильтр по разделу
- `expr.article` (с v3.21.1) — фильтр по артикулу
- 📄 [Экспорт товаров](https://help.horoshop.ua/ru/articles/3960898-api)

### Каталог: коды результата импорта
| Код | Значение |
|---|---|
| 0 | Товар добавлен/обновлён |
| 2 | Не найден `parent_article` |
| 5 | Ошибка изменения раздела |
| 6 | Параметр `title` обязателен (для новых товаров) |
| 11 | **Переданный параметр не найден в шаблоне «Каталог»** |
| 13 | Запись с указанной ссылкой уже существует |
| 15 | Остатки обновлены |
| 22 | Изображение загружено |
| 23 | Некорректная ссылка на изображение |
| 27 | MIME тип изображения недопустим (нужно: jpeg/gif/png) |

📄 [Полная таблица кодов](https://help.horoshop.ua/ru/articles/3960898-api)

### Заказы
- `POST /api/orders/get/` — получение списка с фильтрами `from`, `to`, `status[]`, `ids[]`
- `PUT /api/orders/update/` — обновление статуса + tracking_code
- `POST /api/orders/get_available_statuses` (с v4.0) — список статусов магазина
- 📄 [API заказов](https://help.horoshop.ua/ru/articles/3960898-api)

### Статусы заказов (стандартные ID)
| ID | Статус |
|---|---|
| 1 | Новий / Новый |
| 2 | В обробці / В обработке |
| 3 | **Доставлене / Доставлен** (это `is_successful: 1`) |
| 4 | Не доставлене / Не доставлен |
| 6 | Надіслане / Доставляется |

В `total_sum` лежит сумма заказа без доставки (с учётом скидок). В `total_default` — без скидок.

### Категории / страницы
- `POST /api/pages/export/` с параметром `parent` (по умолчанию 0 — корень)
- Возвращает: `id`, `parent`, `title{ua,ru}`, `discount` (с v4)
- **Не возвращает**: SEO-поля категории, описание, h1 (это правится только в админке)
- 📄 [Pages export](https://help.horoshop.ua/ru/articles/3960898-api)

### Иконки/стикеры
- `POST /api/icons/export/` (**только Хорошоп v4**)
- Возвращает список существующих стикеров с `id`, `title`, `enabled`
- На v3 endpoint недоступен — стикеры применяются через `catalog/import` без валидации (несуществующие молча игнорируются)

## 2. Стикеры в карточке товара

### Системные стикеры (всегда есть, не удаляются, можно отключить)
- **Новинка (авто)** — отображается N дней после добавления (по умолчанию 30)
- **Распродаж / Распродажа** — флажок в свойствах товара
- **Новинка** — флажок в свойствах товара
- **Хіт / Хит** — флажок в свойствах товара
- **Розмір знижки / Размер скидки** — авто, если `discount > 0`
- **Відео / Видео** — авто, если в галерее есть видео
- **Лічильник акції / Счётчик акции** — авто вместе с `countdown_end_time`
- **«Оплата частинами» ПриватБанку**
- **«Покупка частинами» від monobank**

### Кастомные стикеры
- Создаются вручную: **Сайт → Стикери для товарів → Додати**
- **Через API создать нельзя** (нет endpoint'а)
- Способ активации «В свойствах товара» — нужен для применения через `icons[]` в API

### Переменные в тексте стикера
- `{DISCOUNT_PERCENT}` — размер скидки в %
- `{COUNTDOWN_INFO}` — сколько осталось до окончания счётчика акции
- `{PARTS}` — кол-во платежей ПриватБанк «Оплата частями»
- `{MONOBANK_PARTS}` — кол-во платежей monobank «Покупка частями»

### Изображение стикера
- PNG (загружай в 2× для retina): для 60×40 — файл 120×80
- SVG (векторный)

### Стиль стикеров
- 5 предустановленных стилей в **Сайт → Дизайн → Редактор дизайна → Общие настройки → Карточки товаров**

📄 [Стикеры в карточке товара](https://help.horoshop.ua/ru/articles/3240575-стикеры-в-карточке-товара)

## 3. Счётчик обратного отсчёта (countdown)

- Поля товара: `countdown_end_time` (datetime, `YYYY-MM-DD HH:MM:SS`) + `countdown_description` (мультиязычный текст)
- Это **визуальный** элемент, не управляет ценой
- После окончания таймера счётчик автоматически пропадает
- Стикер «Лічильник акції» включается отдельно (в **Сайт → Стикери для товарів**)
- Можно настроить через CSV-импорт: колонки «Артикул», «Дата и время окончания акции», «Текст акции»

📄 [Счётчик обратного отсчёта](https://help.horoshop.ua/ru/articles/5724245-счетчик-обратного-отсчета-до-завершения-акции)

## 4. SEO шаблоны

### Что шаблонизируется
- `<title>`
- `<h1>`
- `<meta name="keywords">`
- `<meta name="description">`

### Где работают
- Страница категории
- Страница категории с фильтром
- Страница бренда
- Страница товара
- Страница новости / блога

### Где живут
**Маркетинг → SEO → SEO шаблоны → +Додати**

### Поля шаблона
- Название (внутреннее, для админки)
- Шаблон (отдельно для каждой языковой версии)
- Тип шаблона (для какого типа страниц)
- Включить (вкл/выкл)
- Раздел (для каких категорий применять; пусто = весь сайт)

### Переменные для страницы товара
| Переменная | Что это |
|---|---|
| `{title}` | Название |
| `{mod_title}` | Название модификации (или общее, если нет) |
| `{article}` | Артикул |
| `{article_for_display}` | Артикул для отображения |
| `{short_description}` | Короткое описание |
| `{brand}` | Бренд |
| `{price}`, `{price_old}` | Цены |
| `{quantity}` | Количество |
| `{color}` | Цвет |
| `{currency}` | Валюта |
| `{parent}` | Название родительского раздела |
| `{site}` | Домен сайта |
| `{phone_number}` | Первый телефон из настроек |

### Важно
- Данные по шаблону **попадают только в HTML страницы**, не в поля БД (`seo_title`, `seo_description` остаются в админке пустыми)
- Если в товаре `seo_title` заполнен вручную — он **переопределяет** шаблон

### Шаблоны для изображений
- alt + title для: превью товаров в категории, главное фото товара, превью галереи, превью раздела, новости, логотип бренда, логотип сайта (только alt)
- Пишутся отдельными шаблонами

📄 [SEO шаблоны](https://help.horoshop.ua/ru/articles/1703563-seo-шаблоны)

## 8. Каталог: структура товаров

### Главные товары и модификации
- Главный товар: `article == parent_article`
- Модификация: `article != parent_article` (`parent_article` указывает на главный)
- У главного товара — общий `description`, `gallery_common`, характеристики
- У модификации могут быть свои `images`, `mod_title`, `price`, `presence`, `gtin`, `mpn`

### Где живёт цвет
- `color` — **top-level поле товара**, НЕ в `characteristics`
- На экспорте: `{"id": 5, "value": {"ru": "Золотистый", "ua": "Золотистий"}}`
- На импорте: строка `"Белый"` или multilang dict

### Характеристики
- Стандартные ключи (документированы): `material`, `weight`, `consist`, `country`, `gender`, `age`, `physics`, `brain`, `social`
- На каждом магазине **могут быть кастомные ключи** — зависит от шаблона данных
- Реальные ключи смотри в `catalog/export`
- Иногда название может быть транслитом (`materal`, `kranaVirobnik`) — особенность настройки магазина

📄 [Модификации товаров](https://help.horoshop.ua/ru/articles/4168442-модификации-товаров)
📄 [Характеристики товаров](https://help.horoshop.ua/ru/articles/3960879-характеристики-товаров)
📄 [Цвета товаров](https://help.horoshop.ua/ru/articles/3961019-характеристики-цветов-товаров-на-сайте)

## 9. Изображения товара

### Типы галерей
- `images` — фото модификации (для каждого SKU)
- `gallery_common` — общие фото для всех модификаций
- `gallery_360` — фото для обзора 360°

### Поддерживаемые форматы
- JPEG, GIF, PNG (per `catalog/processImages` MIME-валидация)
- Загрузка по URL (через `links[]`) или через FTP в `/content/import_images/`

### Параметры импорта
- `images.override` — перезаписывать существующие (default `true`)
- `images.links[]` — массив URL'ов
- `gallery_360.removeAll` — `true` очищает галерею (остальные параметры игнорируются)

### Обзор 360
- Загружается отдельной галереей `gallery_360`
- Имя файла должно содержать `@gallery_360@N.jpg` (где N — порядок)

📄 [Обзор 360](https://help.horoshop.ua/ru/articles/1703567-обзор-360)
📄 [Подготовка файлов для импорта](https://help.horoshop.ua/ru/articles/1684865-импорт-товаров-из-файла)

### Водяной знак
- Настраивается в админке: **Налаштування → Загальні налаштування → Водяний знак**
- Применяется к загружаемым изображениям

📄 [Водяной знак](https://help.horoshop.ua/ru/articles/1703587-водяной-знак)

### Логотип
- Загрузка: **Налаштування → Загальні налаштування → Логотипи**
- Оптимально: PNG в большом разрешении (автоматически отформатируется)
- Отдельные поля: основной, мобильный, футер (белый на прозрачном), для печати (черно-белый)

📄 [Загрузка логотипа](https://help.horoshop.ua/ru/articles/1913435-загрузка-логотипа)

## 10. Скидки и акции

### Виды скидок
- **Скидка на товар** — поле `price_old` + `price`
- **Скидка на раздел** — настраивается на категории (Каталог → Категорія)
- **Накопительная скидка** — для постоянных покупателей
- **Промокод / купон** — единоразовые или многоразовые
- **Карта клиента** — персональная скидка авторизованному

### `discount` (поле товара)
- Если `price_old > price`, и `discount = 0` — пересчитывается автоматически: `(price_old - price) / price_old * 100`
- Через API можно установить вручную

📄 [Какие скидки можно настроить](https://help.horoshop.ua/ru/articles/3960846-какие-скидки-можно-настроить)

📄 [Сертификаты и купоны](https://help.horoshop.ua/ru/articles/3960849-сертификаты-и-купоны)

## 11. Оплата

### «Оплата частями» ПриватБанк
- API поле: `installments_payment.id` (1=выкл, 2=по умолч, 3+=N платежей) — **только v4**
- Активация: **Налаштування → Способи оплати → Оплата частями**
- Подключение через PrivatBank merchant + ID

📄 [Оплата частями ПриватБанк](https://help.horoshop.ua/ru/articles/4098497-оплата-частями-от-приватбанка)

### «Покупка частями» monobank
- API поле: `monobank_installments_payment.id` — **только v4**

📄 [Покупка частями monobank](https://help.horoshop.ua/ru/articles/4098499-покупка-частями-от-monobank)

### Онлайн-оплата
- Подключение через **WayForPay**, **LiqPay**, **Fondy**, **Portmone**, **Privat24**
- 2 режима: моментальный или после подтверждения менеджером
- Настройка: **Налаштування → Способи оплати**

📄 [Онлайн-оплата](https://help.horoshop.ua/ru/articles/3960876-подключение-и-настройка-онлайн-оплаты)

## 12. Доставка

### Поддерживаемые перевозчики
- **Нова Пошта** — отделения и адресная (курьер)
- **Укрпошта** — стандартная и адресная
- **Rozetka Delivery** — выкуп через Розетку
- **Uklon Delivery** — быстрая доставка по городу
- Самовывоз (отделение магазина)

### ТТН (товарно-транспортная накладная)
- Формируется при обработке заказа в админке (для Нової Пошти)
- В API передаётся как `tracking_code` через `orders/update`
- В новых данных — блок `delivery_data` с `tnNumber`, `tnStatusName`, `estimatedDeliveryDate`

## 16. Версии Хорошопа

- **v3** — базовая версия. Нет: `installments_payment`, `monobank_installments_payment`, `unit_of_measurement`, `wholesale_prices`, `icons/export`, `discount` для страниц
- **v4** — текущая. Все эти поля доступны
- **v4.7+** — в `orders/get` товары имеют `type` (`gift`, `gift_parent`, `set_main`, `set_item`)

При импорте полей v4 на v3 — API вернёт код 11.
