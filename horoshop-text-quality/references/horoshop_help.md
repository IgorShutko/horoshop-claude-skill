# Справка Хорошопа — текстовые поля товара

Выжимка из официальной документации `help.horoshop.ua`, релевантная аудиту качества текстов.

---

## Текстовые поля товара (через API)

| Поле | Где видит покупатель | Где живёт в админке | Лимиты best-practice |
|---|---|---|---|
| `title.<lang>` | H1 товара, шапка карточки, листинг | Каталог → Товари → Назва | 50–70 симв. |
| `mod_title.<lang>` | Название модификации в дропдауне | Каталог → Товари → Модифікація | до 50 симв. |
| `description.<lang>` | Полное описание товара (HTML) | Каталог → Товари → Опис | 800–2500 симв. |
| `short_description.<lang>` | Под главным фото на карточке | Каталог → Товари → Короткий опис | 100–250 симв. |
| `marketplace_description.<lang>` | Только в товарных фидах (Rozetka/Google) | Каталог → Товари → Опис для маркетплейсів | 800–1500 симв. |
| `seo_title.<lang>` | `<title>` в HTML | Каталог → Товари → SEO | ≤ 70 симв. |
| `seo_description.<lang>` | `<meta description>` | Каталог → Товари → SEO | 120–160 симв. |
| `seo_keywords.<lang>` | `<meta keywords>` (Google игнорирует, но в Yandex учёт) | Каталог → Товари → SEO | 5–10 ключей |
| `h1_title.<lang>` | `<h1>` если задан явно (иначе title) | Каталог → Товари → SEO | до 80 симв. |

📄 [API: Каталог](https://help.horoshop.ua/ru/articles/3960898-api)

## Когда какое поле использовать

### `title`
Просто название товара. Бренд + модель + ключевая характеристика. Не пихать SEO-ключи. Без CAPS LOCK.

### `description`
Главная страница продаж. Структура: что это → характеристики → польза → варианты использования → доставка/гарантия. HTML с `<p>`, `<ul>`, `<table>` (без inline-стилей — Хорошоп подменяет своими).

### `short_description`
Самая важная часть — видна **до** клика «Подробнее». 2-3 buying-driving факта.

### `marketplace_description`
Идёт в фиды Rozetka, Google Merchant, Facebook. Должно быть «голым» текстом (без HTML), факты + размеры. Если пусто — фид использует `description` (часто перегруженный).

### `seo_title` + `seo_description`
Видны в выдаче Google. Если пусты — Хорошоп подставит из шаблона (Маркетинг → SEO → SEO шаблоны). Но шаблон шаблоном — а на топовые товары лучше уникальные.

### `h1_title`
Только если хочешь развести `title` (что в шапке) и `<h1>` (что для SEO).

## SEO шаблоны — переменные для товаров

| Переменная | Значение |
|---|---|
| `{title}` | Название |
| `{mod_title}` | Название модификации (или общее) |
| `{article}` | Артикул |
| `{short_description}` | Короткое описание |
| `{brand}` | Бренд |
| `{price}`, `{price_old}`, `{quantity}` | Цены и кол-во |
| `{color}` | Цвет |
| `{currency}` | Валюта |
| `{parent}` | Название родительского раздела |
| `{site}` | Домен сайта |
| `{phone_number}` | Первый телефон из контактов |

Пример: `Купити {title} {color} в Києві за {price} {currency} | {site}`

## HTML в `description`

### Что разрешено
- Базовые теги: `<p>`, `<br>`, `<strong>`, `<em>`, `<ul>`, `<ol>`, `<li>`, `<a>`, `<table>`, `<img>`, `<h2>`, `<h3>`
- Атрибуты: `href`, `src`, `alt`, `target`

### Что Хорошоп вычищает / переопределяет
- Inline `style="..."` — переопределяется CSS темы (поэтому inline-стили в админке как «магия» — не работают на проде)
- Скрипты `<script>` — удаляются
- `iframe` — частично (только whitelist, типа YouTube)
- Атрибуты `class`, `id` — могут чиститься

### Best practice
- Использовать структуру: `<p>` для абзацев, `<ul>` для списков преимуществ, `<table>` для характеристик
- Не использовать inline-стили — это сжигает время верстальщика

## Multi-language

Хорошоп поддерживает: ua, ru, en, pl и др. (зависит от настройки магазина).

Через API:
- `{title: {ua: "...", ru: "..."}}`
- Или `{title: "..."}` — записывает во все языки

## Что аудит проверяет (через `catalog/export`)

✅ **Лексические проверки:**
- AI-стоп-слоп паттерны
- Маркетинг-вода
- Бизнес-жаргон
- Бинарные контрасты, false agency, em-dashes (см. [stop-slop](stop-slop/CREDITS.md))

✅ **Технические проверки:**
- Дубли слов (regex)
- CAPS LOCK
- Длинные предложения

❌ **Не проверяет:**
- Полная грамматика (нужен LanguageTool)
- Фактические ошибки в характеристиках (для этого `horoshop-consistency`)
- Согласование родов/падежей
