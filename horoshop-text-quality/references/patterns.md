# Паттерны проверок text-quality

Скилл ищет AI-патерны и слабые тексты в карточках товаров на Хорошопе. Базируется на фреймворке **[stop-slop](stop-slop/CREDITS.md)** (Hardik Pandya, MIT) — структурные правила универсальны, фразы переведены на UA/RU.

## 1. Слова-паразиты (throat-clearing)

Объявление «вот сейчас будет важное» вместо самого важного.

### Українська
- «варто зазначити»
- «варто звернути увагу»
- «слід відмітити», «слід зауважити»
- «зверніть увагу»
- «хотілось би сказати», «хотілося б»
- «треба сказати»
- «по суті»
- «насправді ж»

### Русский
- «стоит отметить»
- «стоит обратить внимание»
- «следует отметить», «следует заметить»
- «необходимо отметить»
- «хотелось бы сказать», «хотелось бы»
- «надо сказать»
- «по сути»
- «на самом деле»

## 2. Эмфазные пустышки (emphasis crutches)

Не несут смысла, добавлены для веса.

### Українська
- «справді», «дійсно»
- «насправді»
- «однозначно», «безумовно»
- «неодмінно»
- «загалом», «в цілому»
- «буквально»
- «вкрай», «вельми»

### Русский
- «действительно», «реально»
- «по-настоящему»
- «безусловно», «однозначно»
- «непременно»
- «в целом», «в общем»
- «буквально», «прямо»
- «крайне», «весьма», «очень»

## 3. Длинные конструкции типа «является»

Замени глаголом действия.

| ❌ | ✅ |
|---|---|
| є/являється | бути (или конкретный глагол) |
| представляє собою / является | без вступления, прямо |
| виступає (як) / выступает | без формальности |
| має місце / имеет место | конкретный глагол |
| складається з | из (или в составе) |
| є чудовим вибором / является отличным выбором | подходит / выберите |

## 4. Маркетинг-вода

### Превосходные степени без основания

#### Українська
- «найвища якість»
- «неперевершений», «непереможний»
- «унікальний»
- «інноваційний», «передовий»
- «лідер ринку»
- «бездоганний»
- «винятковий»
- «революційний»

#### Русский
- «высочайшее качество»
- «непревзойдённый»
- «уникальный»
- «инновационный», «передовой»
- «лидер рынка»
- «безупречный»
- «исключительный»
- «революционный»

### Псевдо-эмоциональные

#### Українська
- «спеціально для вас»
- «саме для вашого комфорту»
- «ваш надійний помічник»
- «ваш найкращий вибір»
- «ваше задоволення — наш пріоритет»

#### Русский
- «специально для вас»
- «именно для вашего комфорта»
- «ваш надёжный помощник»
- «ваш лучший выбор»
- «ваше удовольствие — наш приоритет»

## 5. Бизнес-жаргон

| Українська (избегать) | Замена |
|---|---|
| реалізувати | зробити, виконати |
| впровадити | додати, запустити |
| оптимізувати | покращити, прискорити |
| масштабувати | збільшити |
| синергія, екосистема | прибрати або «комплект» |
| у нашій парадигмі | прибрати |
| з огляду на сучасні реалії | прибрати або «зараз» |

| Русский (избегать) | Замена |
|---|---|
| реализовать | сделать, выполнить |
| внедрить | добавить, запустить |
| оптимизировать | улучшить, ускорить |
| масштабировать | увеличить |
| синергия, экосистема | убрать или «комплект» |
| в современных реалиях | убрать или «сейчас» |

## 6. Неопределённые декларативы (vague declaratives)

«Что-то важное» без указания что именно. Cut.

### Українська
- «причини є структурними»
- «наслідки значні»
- «це має значення»
- «ставки високі»
- «варто звернути увагу на важливість»

### Русский
- «причины структурные»
- «последствия значительны»
- «это имеет значение»
- «ставки высоки»
- «стоит обратить внимание на важность»

**Правило:** если не можешь назвать конкретно ЧТО — удали предложение.

## 7. Структурные паттерны (универсальные — работают на UA/RU/EN)

### Бинарные контрасты

Шаблон «Не X, а Y» — телеграфный реверс. Скажи Y напрямую.

| ❌ | ✅ |
|---|---|
| Не просто куртка, а ціла філософія руху | Куртка для активних рухів |
| Не для всіх — для тих, хто цінує якість | Для тих, хто цінує якість |
| Це не товар, це досвід | (удалить — manipulative) |
| Не дешевий — справжній | Справжній |
| Это не просто мебель, это образ жизни | Мебель для повседневного комфорта |

### Драматическая фрагментация

Сlуint — сtaccato — drama. Перебор.

| ❌ | ✅ |
|---|---|
| Стиль. Комфорт. Якість. | Стиль, комфорт, якість. |
| Куртка. Ось і все. Ось і вся історія. | Куртка з мембраною 10 000 мм. |
| Швидкість. Надійність. Гарантія. Ось наш девіз. | Гарантія + швидке постачання. |

### Риторические постановки

| ❌ | ✅ |
|---|---|
| А що, як я скажу, що... | (удалить, говори напрямую) |
| Подумайте про це: | (удалить) |
| Ось що я маю на увазі: | (удалить) |
| Ну й добре. | (удалить) |

### Ложная агентивность

Неодушевлённое делает глагол человека. Найди человека.

| ❌ | ✅ |
|---|---|
| Тканина дозволяє вам почуватися комфортно | Ви почуваєтеся комфортно завдяки тканині |
| Куртка пропонує захист | Куртка захищає / Ви захищені |
| Технологія забезпечує | Завдяки технології ви отримуєте |
| Дизайн розповідає історію | (удалить — манипулятивно) |
| Этот матрас знает, что вам нужно | Этот матрас подходит для… |

### Голос рассказчика-издалека

| ❌ | ✅ |
|---|---|
| Ніхто не дизайнував це випадково | Дизайнери продумали кожну деталь |
| Люди звикли вважати, що... | Ви, ймовірно, думаєте, що... |
| У сучасному світі... | (удалить — пустая рамка) |

## 8. Технические баги (regex)

### Дубли слов подряд
Регекс: `\b(\w{2,})\s+\1\b`

Примеры:
- «и и поэтому»
- «який який»
- «так так»

(Исключения — «так-так» как разговорное междометие)

### Caps Lock
Слова из ≥6 заглавных подряд:
- «КУПИТЕ ПРЯМО СЕЙЧАС»
- «АКЦІЯ ТІЛЬКИ СЬОГОДНІ»

(Исключения — аббревиатуры до 6 букв: GTIN, MPN, USB)

### Повтор букв
Регекс: `(\w)\1{3,}`

Примеры: «приветттт», «оооочень»

### Длинные предложения
Порог: >35 слов в одном предложении.

Стандарт читаемости — 15-20 слов. Длинное теряется при сканировании.

### Em dashes (—)
В украинской и русской типографике используется тире через пробелы (« — ») или дефис («-»). Em-dash без пробелов — английский стиль, AI-tell в продающих текстах.

Регекс: `\w—\w` (em-dash примыкает к словам без пробела) или просто `—` для общей частоты.

### Многоточие как драма
Если в коротком тексте >2 многоточий — драматизация.

## 9. Lazy extremes (ленивые крайности)

«Все», «всегда», «никогда», «каждый», «каждый раз».

### Українська
- «завжди»
- «ніколи»
- «кожен»
- «всі»
- «жоден»

### Русский
- «всегда»
- «никогда»
- «каждый»
- «все»
- «ни один»

**Правило:** если используешь крайность — должен быть конкретный пруф рядом.

## 10. Scoring (1-10 по 5 измерениям)

Применяется в `TEXT_QUALITY_REPORT.md` как финальная сводка по магазину:

| Измерение | Вопрос |
|---|---|
| **Прямота** | Утверждения или объявления? |
| **Ритм** | Разнообразный или метроном? |
| **Доверие** | Уважает интеллект читателя? |
| **Аутентичность** | Звучит как человек? |
| **Плотность** | Есть ли что вырезать? |

**< 35/50** — описания требуют переписывания.

## Что НЕ ловим

- Полную грамматическую проверку (используй LanguageTool)
- Стилистический анализ (sentiment, тон)
- Проверку согласования (роды/падежи)
- Семантические противоречия (этим занимается `horoshop-consistency`)

Скилл фокусируется на **очевидных паттернах**, которые легко найти регексами и которые часто появляются в:
1. AI-сгенерированных текстах без редактуры (ChatGPT-стиль)
2. Шаблонных описаниях из copy-paste
3. Багах при импорте из CSV
