# Паттерны проверок text-quality

## AI-стоп-слоп (русский + украинский)

### Заглушки и пустословы
- является / являє собою
- представляет собой
- при этом / при цьому
- по сути
- в целом / загалом
- буквально / буквально
- крайне / вкрай
- весьма
- не просто [Х], а целый [Y]

### Связки
- стоит отметить, что / варто зазначити
- хотелось бы / хотілось би
- следует отметить
- стоит обратить внимание

### Шаблоны структуры
- Хотите [X]? Тогда вам сюда.
- Не просто [товар], а целый [абстракция].
- В мире, где [клише]...
- Каждый из нас знает...

## Маркетинг-вода

### Превосходные степени без основания
- высочайшее качество / найвища якість
- непревзойденный / неперевершений
- уникальный / унікальний
- инновационный / інноваційний
- передовой
- лидер рынка / лідер ринку

### Псевдо-эмоциональные
- специально для вас / спеціально для вас
- именно для вашего комфорта
- ваш надежный помощник
- ваш лучший выбор

## Технические баги

### Дубли слов подряд
Регекс: `\b(\w{2,})\s+\1\b`

Примеры (плохо):
- «и и поэтому»
- «который который»
- «так так»

(NB: исключения — «так-так» как разговорное междометие)

### Caps Lock
Слова из ≥6 заглавных подряд:
- «КУПИТЕ ПРЯМО СЕЙЧАС»
- «АКЦИЯ ТОЛЬКО СЕГОДНЯ»

(NB: исключения — аббревиатуры до 6 букв: GTIN, MPN, USB, USA, EU)

### Повтор букв
Регекс: `(\w)\1{3,}`

Примеры:
- «приветттт»
- «оооочень»

### Длинные предложения
Порог: >35 слов в одном предложении.

Почему важно: средний пользователь читает по диагонали, длинные предложения теряются. Стандарт читаемости — 15-20 слов.

## Что НЕ ловим

Скилл не делает:
- Полную грамматическую проверку (используй LanguageTool)
- Проверку запятых
- Стилистический анализ
- Проверку согласования по родам/падежам

Скилл фокусируется на **очевидных паттернах** которые легко найти регексами и которые часто появляются в:
1. AI-сгенерированных текстах (без редактуры)
2. Шаблонных описаниях из copy-paste
3. Багах при импорте из CSV
