# Horoshop Text Quality

Аудит качества текстов в карточках товаров.

## Что проверяет

| Чек | Что ищет |
|---|---|
| AI-стоп-слоп | Заглушки и пустословы характерные для AI-текстов: «является», «при этом», «в целом», «буквально», «не просто X, а целый Y» |
| Маркетинг-вода | «высочайшее качество», «инновационный», «уникальный», «специально для вас» |
| Повторы слов | «и и», «так так», «который который» — баг ввода |
| Длинные предложения | >35 слов в одном предложении (плохо для скана) |
| Capslock | Слова из >5 заглавных букв (кричит на читателя) |
| Дубли букв | «приветттт», «ооочень» — баг ввода |
| Несоответствие языка | Русский в украинской версии (если магазин mostly UA) |

## Pipeline

```
[1] Auth + выгрузка каталога
[2] Сбор текстов: title, description (HTML stripped), short_description, marketplace_description, seo_title, seo_description, h1_title
[3] Прогон каждого текста через 7 проверок
[4] TEXT_QUALITY_REPORT.md с примерами
```

## Использование

```bash
mkdir -p text_<domain>
cd text_<domain>
HOROSHOP_DOMAIN=<DOMAIN> HOROSHOP_LOGIN=<LOGIN> HOROSHOP_PASSWORD=<PASSWORD> \
  python3 ${SKILL_DIR}/scripts/text_quality.py
```

Опции:
- `--from-file catalog.json` — без API
- `--lang ua/ru/auto` — какой язык приоритетный (default: ua)
- `--min-issues 1` — порог проблем для попадания в отчёт

## Output

- `text_quality.json` — все находки
- `TEXT_QUALITY_REPORT.md` — отчёт с примерами

## Что НЕ делает

- ❌ Не правит автоматом — это работа редактора (или другого скилла типа `content-fill` для генерации с нуля)
- ❌ Не делает полную грамматическую проверку — это узкая задача для LanguageTool. Скилл ловит явные паттерны
- ❌ Не отличает «AI-сгенерированный» от «человек написал шаблонно» — оба ловятся одинаковыми паттернами
