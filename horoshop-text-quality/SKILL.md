# Horoshop Text Quality

Аудит качества текстов в карточках товаров. Базируется на фреймворке **[stop-slop](references/stop-slop/CREDITS.md)** (Hardik Pandya, MIT) — структурные правила универсальны, паттерны фраз переведены на UA/RU.

## Что проверяет (13 категорий)

| # | Категория | Что ищет |
|---|---|---|
| 1 | Throat-clearers | «варто зазначити», «слід відмітити», «стоит обратить внимание» |
| 2 | AI-стоп-слоп | «являє собою», «при цьому», «справді», «дійсно», «не просто» |
| 3 | Маркетинг-вода | «найвища якість», «неперевершений», «спеціально для вас» |
| 4 | Бизнес-жаргон | «реалізувати», «впровадити», «синергія», «масштабувати» |
| 5 | Vague declaratives | «причини є структурними», «це має значення» — без конкретики |
| 6 | Lazy extremes | «завжди», «ніколи», «кожен» — без числового пруфа |
| 7 | Бинарные контрасты | «не X, а Y» — телеграфный реверс |
| 8 | False agency | «тканина дозволяє», «технологія забезпечує» — неодушевлённое + чел. глагол |
| 9 | Em dashes (—) | Без пробелов, английский стиль |
| 10 | Повторы слов | «и и», «так так» — баг ввода |
| 11 | CAPS LOCK | Слова из ≥6 заглавных |
| 12 | Дубли букв | «приветттт» — баг ввода |
| 13 | Длинные предложения | >35 слов |

## Stop-Slop Score (1-10 по 5 измерениям)

Финальная сводка по магазину:

| Измерение | Что отвечает |
|---|---|
| Прямота | Утверждения или объявления? |
| Ритм | Разнообразный или метроном? |
| Доверие | Уважает интеллект читателя? |
| Аутентичность | Звучит как человек? |
| Плотность | Есть ли что вырезать? |

**< 35/50** — описания требуют переписывания.

## Pipeline

```
[1] Auth + выгрузка каталога
[2] Сбор текстов: title, description (HTML stripped), short_description, marketplace_description, seo_title, seo_description, h1_title
[3] Прогон каждого текста через 13 проверок (см. таблицу выше)
[4] Stop-Slop Score (1-10 × 5 измерений)
[5] TEXT_QUALITY_REPORT.md с примерами и приоритетами
```

## Использование

```bash
mkdir -p text_<domain>
cd text_<domain>
HOROSHOP_DOMAIN=<DOMAIN> HOROSHOP_LOGIN=<LOGIN> HOROSHOP_PASSWORD=<PASSWORD> \
  python3 ${SKILL_DIR}/scripts/text_quality.py
```

Опции:
- `--from-file catalog.json` — без API
- `--lang ua/ru/auto` — какой язык приоритетный (default: ua)
- `--min-issues 1` — порог проблем для попадания в отчёт

## Output

- `text_quality.json` — все находки
- `TEXT_QUALITY_REPORT.md` — отчёт с примерами

## Что НЕ делает

- ❌ Не правит автоматом — это работа редактора (или другого скилла типа `content-fill` для генерации с нуля)
- ❌ Не делает полную грамматическую проверку — это узкая задача для LanguageTool. Скилл ловит явные паттерны
- ❌ Не отличает «AI-сгенерированный» от «человек написал шаблонно» — оба ловятся одинаковыми паттернами
