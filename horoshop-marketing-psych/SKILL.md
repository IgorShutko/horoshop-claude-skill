# Horoshop Marketing Psychology

Применение психо-приёмов к карточкам товаров для роста конверсии.

## 7 приёмов которые применяет

### 1. Scarcity (Дефицит)
- «Залишилось 3 шт.», «Останній розмір»
- На карточке + в стикере (`icons[]`)

### 2. Social proof (Соц. доказательство)
- «23 покупки за тиждень», «Топ-3 в категорії»
- Стикер «Хіт продажів» / «Бестселер»

### 3. Anchoring (Якорь)
- Старая цена жирным крестом + новая → разница в гривнах
- Сравнение с конкурентом

### 4. Loss aversion (Страх потери)
- «Не пропустіть знижку до півночі»
- В description: «Кожен п'ятий покупець повертається за наволочкою — не залиште без»

### 5. Reciprocity (Взаимность)
- Подарок при заказе («Безкоштовний наматрацник у подарунок»)
- Бесплатная доставка от X грн

### 6. Authority (Авторитет)
- «Власне виробництво з 2015 року»
- Сертификаты, награды если есть

### 7. Commitment & consistency
- «Обери розмір — побачиш точну ціну»
- Quiz / калькулятор размера → micro-yes → покупка

## Pipeline

```
[1] find_targets.py — выгрузка каталога, выбор товаров для psych-обогащения
    Приоритет: товары группы A из ABC (если есть SALES_REPORT.md)
    Или: все товары со скидкой (price_old > price)
        ↓
[2] Claude (в чате):
    - Читает targets.json
    - Выбирает приёмы под товар (не все 7 — обычно 2-3)
    - Генерирует переработанные description / short_description / icons
    - Сохраняет в proposed_psych.json
        ↓
[3] apply_psych.py --preview-only — diff
        ↓
[4] apply_psych.py — импорт через catalog/import
```

## Использование

```bash
mkdir -p psych_<domain>
cd psych_<domain>
HOROSHOP_DOMAIN=<DOMAIN> HOROSHOP_LOGIN=<LOGIN> HOROSHOP_PASSWORD=<PASSWORD> \
  python3 ${SKILL_DIR}/scripts/find_targets.py [--abc-only] [--discount-only]
```

Опции:
- `--abc-only` — только товары группы A из ABC-анализа (требует `SALES_REPORT.md` рядом)
- `--discount-only` — только товары со скидкой
- `--limit 30` — макс товаров для обработки (default 30, чтоб Claude'у не задохнуться)

## Что НЕ делать

- ❌ Не применять все 7 приёмов сразу к одному товару — выглядит как спам
- ❌ Не врать в scarcity («Залишилось 3 шт» если на самом деле 50) — это ловушка для бренда
- ❌ Не использовать FOMO для дешёвых товаров — не работает, выглядит навязчиво
- ❌ Не переписывать характеристики — только маркетинг-обвязку

## ⚠️ Важно про стикеры (`icons[]`)

В Horoshop стикеры — это **именованные сущности** в админке (Сайт → Стикеры для товаров), а не свободный текст. Поле `icons[]` через API ищет совпадение по имени.

**Системные стикеры** (всегда доступны): «Хіт», «Распродажа», «Новинка», «Розмір знижки», «Відео», «Лічильник акції», «Новинка (авто)», «Оплата частинами» ПриватБанка, «Покупка частинами» від monobank.

**Кастомные стикеры** (например «Залишилось 3 шт», «Топ-3 у категорії», «Хіт продажів»): через API **создать нельзя** — нет такого endpoint'а. Только вручную в админке: **Сайт → Стикеры для товаров → Додати**, способ активации «В свойствах товара».

### Как `apply_psych.py` обходит это

Перед записью скрипт автоматически:
1. Запрашивает существующие стикеры через `icons/export` (v4 only — на v3 пропускает валидацию)
2. Фильтрует `icons[]` в `proposed_psych.json` — оставляет только те, что действительно есть в магазине
3. Печатает список **отброшенных** стикеров с инструкцией как их создать в админке

Так что Claude может смело генерировать любые названия стикеров — несуществующие просто не попадут в API-запрос, а тексты `description` / `short_description` сохранятся.

### Альтернативные носители scarcity без кастомных стикеров

Если не хочется заводить стикеры — используй doc-blessed механики которые работают через API на любой версии Хорошопа:
- `countdown_end_time` + `countdown_description` — Хорошоп сам отрисует таймер на странице товара и системный стикер «Лічильник акції»
- Текст в `description` / `short_description` — самый универсальный путь
- `discount` поле — автоматически включает системный стикер «Розмір знижки»

## Этика

Психологические триггеры — мощный инструмент. Используй честно:
- Scarcity только если реально мало
- Social proof только с реальными цифрами
- «Купите сегодня и получите скидку» — да; «Цена вырастет завтра» если не вырастет — нет
