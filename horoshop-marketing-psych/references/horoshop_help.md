# Справка Хорошопа — стикеры, акции, скидки

Выжимка из официальной документации `help.horoshop.ua`, релевантная маркетинг-психологии в карточках товара.

---

## Стикеры в карточке товара

### Системные стикеры (есть всегда)

Их **нельзя удалить**, но можно отключить.

| Стикер UA | Стикер RU | Способ активации |
|---|---|---|
| Хіт | Хит | Флажок «В свойствах товара» (через API: `icons[]`) |
| Розпродаж | Распродажа | Флажок «В свойствах товара» |
| Новинка | Новинка | Флажок «В свойствах товара» |
| Розмір знижки | Размер скидки | **Авто** при `discount > 0` |
| Відео | Видео | **Авто** если в галерее есть видео |
| Лічильник акції | Счётчик акции | **Авто** при заполненном `countdown_end_time` |
| Новинка (авто) | Новинка (авто) | **Авто** N дней после добавления (по умолч. 30) |
| «Оплата частинами» ПриватБанку | «Оплата частями» ПриватБанка | При включённой `installments_payment` |
| «Покупка частинами» від monobank | «Покупка частями» от monobank | При включённой `monobank_installments_payment` |

### Кастомные стикеры

Создаются вручную: **Сайт → Стикери для товарів → Додати**

**Через API создать нельзя** — нет endpoint'а. Через `icons/export` (v4) можно только прочитать список существующих.

### Поля кастомного стикера
- **Название** — для админки и API-привязки
- **Отображать** — глобальный вкл/выкл
- **Текст** на стикере — обязательно. Поддерживает переменные:
  - `{DISCOUNT_PERCENT}` — размер скидки %
  - `{COUNTDOWN_INFO}` — сколько осталось до окончания счётчика
  - `{PARTS}` — кол-во платежей ПриватБанк
  - `{MONOBANK_PARTS}` — кол-во платежей monobank
- **Способ активации:**
  - Новый товар (auto)
  - **В свойствах товара** ← **этот нужен для применения через API**
  - Скидка (auto)
  - Видео (auto)
  - Счётчик акции (auto)
  - Оплата частями (auto)
- **Изображение** — PNG (в 2× для retina) или SVG. Если есть — отображается вместо текста (но в мобильной версии каталога всё равно текст)
- **Подсказка** — tooltip при наведении

📄 [Стикеры в карточке товара](https://help.horoshop.ua/ru/articles/3240575-стикеры-в-карточке-товара)

## Счётчик обратного отсчёта (countdown)

### Поля API
- `countdown_end_time` — datetime в формате `YYYY-MM-DD HH:MM:SS`
- `countdown_description.<lang>` — текст акции (HTML поддерживается)

### Что происходит
- На странице товара появляется блок с таймером + текстом
- На фото товара — стикер «Лічильник акції» (если включён)
- После окончания счётчика блок и стикер автоматически пропадают

### Важно
- Это **визуальный элемент** — не управляет ценой
- Сам по себе цену не меняет
- Чтобы скидка работала — задавай `price_old` + `price`

### Куда настраивается отображение
**Сайт → Дизайн → Редактор дизайна → Сторінка товару → Структура сторінки → Зворотний відлік акції**

📄 [Счётчик обратного отсчёта](https://help.horoshop.ua/ru/articles/5724245-счетчик-обратного-отсчета-до-завершения-акции)

## Скидки (для anchoring)

### Через `price_old` + `price`
Самый простой способ показать «было / стало»:
- `price_old: 999` (старая цена, зачёркнутая)
- `price: 599` (новая)
- `discount` — Хорошоп пересчитает автоматически (или укажи явно: `discount: 40` = 40%)

### Скидка на раздел
- Настраивается на категории: **Каталог → Категорія → Знижка на розділ**
- Через API не управляется

### Накопительные скидки
- Настраиваются глобально: **Маркетинг → Знижки → Накопичувальні**
- По сумме покупок клиента
- Через API не управляется

### Промокоды / купоны
- **Маркетинг → Знижки → Сертифікати та купони**
- Через API не управляется

### Карта клиента
- Персональная скидка авторизованному
- **Маркетинг → Знижки → Карта клієнта**

📄 [Какие скидки можно настроить](https://help.horoshop.ua/ru/articles/3960846-какие-скидки-можно-настроить)
📄 [Накопительные скидки](https://help.horoshop.ua/ru/articles/3960847-накопительные-скидки)

## Подарки к товару (для reciprocity)

### Через API
- `gifts[]` — массив с артикулами товаров-подарков
- Сработает только если на сайте включена функция подарков

### Где включить
**Налаштування → Загальні налаштування → Товари → Подарунки до товару**

### Как отображается
- На странице товара — блок «До цього товара в подарунок»
- В корзине — позиция с ценой 0
- В заказе через API — товар с `type: gift` (родитель — `type: gift_parent`, v4.7+)

📄 [Товар в подарок](https://help.horoshop.ua/ru/articles/3960850-товар-в-подарок)

## Что работает через API (для marketing-psych)

| Прием | Поле API | Доп. условие |
|---|---|---|
| Anchoring | `price_old` + `price` (автоматически считает `discount`) | — |
| Scarcity (через текст) | `description`, `short_description` | — |
| Scarcity (через timer) | `countdown_end_time` + `countdown_description` | — |
| Scarcity (через системный стикер) | `discount > 0` → авто-стикер «Розмір знижки» | — |
| Social proof (через стикер «Хіт») | `icons: ["Хіт"]` | Системный, всегда работает |
| Loss aversion (через timer) | `countdown_end_time` | — |
| Reciprocity (бонус-товар) | `gifts: ["артикул"]` | Должна быть включена функция подарков |
| Reciprocity (упоминание в тексте) | `description`, `short_description` | — |
| Authority (упоминание сертификатов в тексте) | `description` | — |

## Что НЕ работает через API (только админка)

| Действие | Где делать |
|---|---|
| Создать кастомный стикер | Сайт → Стикери для товарів |
| Настроить накопительные скидки | Маркетинг → Знижки → Накопичувальні |
| Настроить купоны | Маркетинг → Знижки → Сертифікати та купони |
| Настроить персональные скидки | Маркетинг → Знижки → Карта клієнта |
| Изменить стиль стикеров | Сайт → Дизайн → Редактор дизайна |

## Этика

Платформа Хорошоп **не требует** правдивости в скидках или сроках акций — это ответственность магазина. Но Google Merchant **банит** за фейковые `price_old` (правило 30-day rule: цена должна быть реальной в течение последних 30 дней).

При генерации `proposed_psych.json` Claude должен:
- НЕ писать «Залишилось 3 шт» если на складе 50
- НЕ ставить `countdown_end_time` который сбрасывается каждый день
- НЕ выдумывать `price_old` для мнимой скидки
