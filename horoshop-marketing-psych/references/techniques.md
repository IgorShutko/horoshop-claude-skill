# Психологические приёмы для карточек товаров

> Этот скилл применяет приёмы **только в тексте** (`description`, `short_description`, `marketplace_description`). Стикеры (`icons[]`) — отдельная админская тема: кастомные стикеры через API создать невозможно, см. `references/horoshop_help.md`.

## 7 классических приёмов + рецепты

### 1. Scarcity (Дефицит)

**Когда применять:** товар реально в дефиците (мало в стоке, ограниченная коллекция)

**Где:**
- В description: «У наявності лишилось N одиниць — наступне постачання очікується через 2-3 тижні.»
- В short_description: «Останній розмір M»
- Дополнительно (вне этого скилла): через `countdown_end_time` + `countdown_description` Хорошоп автоматически отрисует таймер на странице товара. Это работает через API, но настраивается отдельно (например через `horoshop-full-audit` или вручную в админке)

**❌ Не делать:** ставить «залишилось 3 шт» если на складе 50. Сжигает доверие на повторных визитах.

### 2. Social proof (Социальное доказательство)

**Когда:** есть реальные цифры продаж / отзывы / упоминания

**Где:**
- В description: «Цей комплект обрали 247 покупців за останній місяць — топ-1 у категорії "X".»
- В short_description: «247 покупців обрали»

**Подсказка:** системный стикер «Хіт» включается через свойство товара в админке без скилла — если хочется визуальный маркер.

**❌ Не делать:** «лучший в мире» без подкрепления цифрами.

### 3. Anchoring (Якорь)

**Когда:** есть скидка (`price_old > price`)

**Где:**
- В description: «**999 грн** ~~~~ → 599 грн. Економія 400 грн (40%).»
- Сравнение: «У конкурентів аналогічна якість від 800 грн.»

**❌ Не делать:** придумывать фейковую старую цену для якоря — Google Merchant за это банит.

### 4. Loss aversion (Страх потери)

**Когда:** действует временное предложение (акция / промокод / бесплатная доставка)

**Где:**
- В description CTA: «Не пропустіть — після 31 грудня ціна повертається до базової 999 грн.»
- В short_description: «До 31 грудня — знижка 40%»

**❌ Не делать:** ставить таймер «1 день до конца» который ресетится каждый день.

### 5. Reciprocity (Взаимность)

**Когда:** есть бонус / подарок к покупке

**Где:**
- В description: «До замовлення — безкоштовний наматрацник у подарунок (вартість 199 грн).»
- В short_description: «+ Подарунок: наматрацник»

**Дополнительно (вне этого скилла):** `gifts[]` поле через `catalog/import` — привязка реального товара-подарка по артикулу. Требует включённой функции «Подарки» в админке. Этот скилл текстом упоминает подарок, но не настраивает API-привязку.

**Эффект:** норма взаимности — получивший «подарок» чаще доводит покупку.

### 6. Authority (Авторитет)

**Когда:** есть факты о бренде / производстве / сертификации

**Где:**
- В description блок «Про виробництво»: «Власне виробництво з 2015 року, сертифікат якості Oeko-Tex.»

**❌ Не делать:** «лидер рынка» без подтверждения.

### 7. Commitment & consistency

**Когда:** товар имеет вариации (размер, цвет)

**Где:**
- В short_description: «Оберіть розмір — побачите точну ціну»
- В description ведёт через micro-yes: «Так, я хочу комплект» → выбор размера → CTA

**Эффект:** малое первое «да» делает второе «да» (покупку) проще.

## Что генерировать в `proposed_psych.json`

Для каждого товара из `targets.json`:

```json
{
  "article": "1234",
  "techniques_applied": ["anchoring", "social_proof", "scarcity"],
  "description": "<HTML с инкорпорированными приёмами>",
  "short_description": "Короткий текст с триггером"
}
```

Поле `icons[]` не обрабатывается — даже если включить в JSON, скрипт его проигнорирует.

## Сколько приёмов на товар

- **2-3 приёма** — оптимум. Один основной + 1-2 поддерживающих.
- **>4 приёмов** — выглядит как спам, конверсия падает
- **1 приём** — недостаточно для overlap-эффекта

## Комбинации которые работают

| Категория | Приёмы |
|---|---|
| Дешёвый товар (<500 грн) | anchoring + scarcity |
| Средний (500-2000) | anchoring + social proof + reciprocity |
| Дорогой (>2000) | authority + social proof + commitment |
| Сезонный | loss aversion + scarcity |
| Подарочный | reciprocity + social proof |

## Этика

Маркетинг-психология может стать манипуляцией если:
- Цифры выдуманы
- Срочность фейковая
- Дефицит фейковый

Это работает в краткосрочной перспективе, но убивает LTV. Используй честно — клиент возвращается.
