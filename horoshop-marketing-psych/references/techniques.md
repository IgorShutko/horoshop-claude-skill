# Психологические приёмы для карточек товаров

## 7 классических приёмов + рецепты

### 1. Scarcity (Дефицит)

**Когда применять:** товар реально в дефиците (мало в стоке, ограниченная коллекция)

**Где:**
- В `icons[]`: «Залишилось 3 шт.», «Останній розмір», «Тільки 5 одиниць» — *кастомные стикеры, должны быть заведены в админке (Сайт → Стикеры для товаров → Додати)*
- В description: «У наявності лишилось N одиниць — наступне постачання очікується через 2-3 тижні.»
- Через `countdown_end_time` + `countdown_description` — Хорошоп автоматически отрисует таймер на странице товара и системный стикер «Лічильник акції»

**❌ Не делать:** ставить «залишилось 3 шт» если на складе 50. Сжигает доверие на повторных визитах.

**Альтернатива через API без кастомных стикеров:** только текст в `description` и `short_description`. Это сработает на любом магазине без настройки админки.

### 2. Social proof (Социальное доказательство)

**Когда:** есть реальные цифры продаж / отзывы / упоминания

**Где:**
- `icons[]`: «Хіт» (системный) или кастомные «Хіт продажів», «Топ-3 у категорії», «100+ замовлень за тиждень»
- description блок: «Цей комплект обрали 247 покупців за останній місяць — топ-1 у категорії "X".»

**Системный стикер** «Хіт» включается через свойство товара → доступен сразу, без настройки.

**❌ Не делать:** «лучший в мире» без подкрепления цифрами.

### 3. Anchoring (Якорь)

**Когда:** есть скидка (price_old > price)

**Где:**
- В description: «**999 грн** ~~~~ → 599 грн. Економія 400 грн (40%).»
- Сравнение: «У конкурентів аналогічна якість від 800 грн.»

**❌ Не делать:** придумывать фейковую старую цену для якоря — Google Merchant за это банит.

### 4. Loss aversion (Страх потери)

**Когда:** действует временное предложение (акция / промокод / бесплатная доставка)

**Где:**
- Стикер: «Знижка діє ще 2 дні»
- description CTA: «Не пропустіть — після 31 грудня ціна повертається до базової 999 грн.»

**❌ Не делать:** ставить таймер «1 день до конца» который ресетится каждый день.

### 5. Reciprocity (Взаимность)

**Когда:** есть бонус / подарок к покупке

**Где:**
- description: «До замовлення — безкоштовний наматрацник у подарунок (вартість 199 грн).»
- Стикер: «+ Подарунок»
- `gifts[]` через API (см. `horoshop-full-audit/references/api_quickref.md`)

**Эффект:** норма взаимности — получивший «подарок» чаще доводит покупку.

### 6. Authority (Авторитет)

**Когда:** есть факты о бренде / производстве / сертификации

**Где:**
- description блок «Про виробництво»: «Власне виробництво з 2015 року, сертифікат якості Oeko-Tex.»
- Логотипы партнёров / сертификатов в галерее

**❌ Не делать:** «лидер рынка» без подтверждения.

### 7. Commitment & consistency

**Когда:** товар имеет вариации (размер, цвет)

**Где:**
- В заголовке: «Оберіть розмір — побачите точну ціну»
- Описание ведёт через micro-yes: «Так, я хочу комплект» → выбор размера → CTA

**Эффект:** малое первое «да» делает второе «да» (покупку) проще.

## Что генерировать в `proposed_psych.json`

Для каждого товара из `targets.json`:

```json
{
  "article": "1234",
  "techniques_applied": ["anchoring", "social_proof", "scarcity"],
  "description": "<HTML с инкорпорированными приёмами>",
  "short_description": "...",
  "icons": ["Хіт", "Распродажа"]
}
```

### Про поле `icons[]`

Можно указывать любые названия — `apply_psych.py` перед записью валидирует их через `icons/export` и **отбросит несуществующие**. Тексты в `description` / `short_description` запишутся в любом случае.

**Безопасные названия (системные стикеры — есть всегда):**
- «Хіт», «Распродажа» / «Розпродаж», «Новинка»
- «Розмір знижки» / «Размер скидки» (включается автоматически при `discount > 0`)
- «Лічильник акції» / «Счетчик акции» (автоматически при `countdown_end_time`)

**Кастомные** («Залишилось 3 шт», «Топ-3 у категорії», «Хіт продажів»):
- Сначала создай в админке (Сайт → Стикеры для товаров → Додати)
- Способ активации — «В свойствах товара»
- Только потом включай в `icons[]`. Если не создал — `apply_psych.py` пропустит и покажет список

## Сколько приёмов на товар

- **2-3 приёма** — оптимум. Один основной + 1-2 поддерживающих.
- **>4 приёмов** — выглядит как спам, конверсия падает
- **1 приём** — недостаточно для overlap-эффекта

## Комбинации которые работают

| Категория | Приёмы |
|---|---|
| Дешёвый товар (<500 грн) | anchoring + scarcity |
| Средний (500-2000) | anchoring + social proof + reciprocity |
| Дорогой (>2000) | authority + social proof + commitment |
| Сезонный | loss aversion + scarcity |
| Подарочный | reciprocity + social proof |

## Этика

Маркетинг-психология может стать манипуляцией если:
- Цифры выдуманы
- Срочность фейковая
- Дефицит фейковый

Это работает в краткосрочной перспективе, но убивает LTV. Используй честно — клиент возвращается.
