# Справка Хорошопа — фото и галереи

Выжимка из официальной документации `help.horoshop.ua`, релевантная аудиту фотографий товаров.

---

## Типы галерей в Хорошопе

| Поле API | Что это | Где в админке |
|---|---|---|
| `images` | Фото для **модификации** (свои на каждый SKU) | Каталог → Товари → Фото |
| `gallery_common` | **Общие** фото для всех модификаций | Каталог → Товари → Загальна галерея |
| `gallery_360` | Обзор 360° — серия фото с разных ракурсов | Каталог → Товари → Огляд 360 |

📄 [Подготовка файлов для импорта](https://help.horoshop.ua/ru/articles/1684865-импорт-товаров-из-файла)

## Технические требования

### Форматы (per `catalog/processImages` MIME)
- `image/jpeg` (JPG)
- `image/png` (PNG)
- `image/gif` (GIF)

Другие форматы (WebP, AVIF, TIFF) **отклоняются**: код 27 «MIME тип не соответствует допустимым».

### Загрузка
- **Через URL**: в `catalog/import` → `images.links[]` (массив URL'ов)
- **Через FTP**: положить в `/content/import_images/` → вызвать `catalog/processImages`
  - Имя файла: `<article>@<index>.jpg` для основной галереи
  - Имя файла: `<article>@gallery_360@<index>.jpg` для 360°
  - Имя файла: `<article>@gallery_common@<index>.jpg` для общей галереи

### Параметры импорта
- `images.override` — `true` (default) перезаписывает, `false` добавляет
- `gallery_360.removeAll: true` — очищает галерею (остальные параметры игнорируются)

### Коды ошибок при загрузке
| Код | Значение |
|---|---|
| 22 | Изображение успешно загружено |
| 23 | Некорректная ссылка на изображение |
| 24 | Ошибка при записи изображения |
| 25 | Неизвестная ошибка при загрузке |
| 26 | Ошибка при загрузке изображения |
| 27 | MIME-тип не соответствует jpeg/png/gif |
| 28 | Галерея очищена (при `removeAll: true`) |

📄 [API: Каталог → Импорт](https://help.horoshop.ua/ru/articles/3960898-api)

## Обзор 360°

- Загружается отдельной галереей `gallery_360`
- Минимум — 12 фото (стандарт e-commerce; платформа не ограничивает)
- Отображается каруселью с возможностью drag-вращения
- На странице товара показывается отдельной вкладкой / переключателем

📄 [Обзор 360](https://help.horoshop.ua/ru/articles/1703567-обзор-360)

## Водяной знак

- Настраивается в админке: **Налаштування → Загальні налаштування → Водяний знак**
- Применяется к **новым** загружаемым изображениям (не пересохраняет старые автоматически)
- Поддерживает прозрачность, размер, позицию (углы и центр)
- Требования: PNG с прозрачностью, желательно SVG

📄 [Водяной знак](https://help.horoshop.ua/ru/articles/1703587-водяной-знак)

## Требования к качеству фото (best practices)

> Платформа не предписывает чёткие requirements, но рекомендуемая практика для e-commerce:

| Параметр | Рекомендация | Почему |
|---|---|---|
| Количество фото | ≥ 4 на товар | Меньше — конверсия в 2-3× ниже |
| Разрешение | ≥ 1000px по короткой стороне | Зум/детализация |
| Размер файла | ≤ 500 КБ | LCP / Core Web Vitals |
| Формат | JPG для фото, PNG для лого/прозрачных | Баланс качества/веса |
| Главное фото | Товар на белом фоне | E-commerce стандарт |
| Дополнительные | Ракурсы (вид сбоку, сзади), макро деталей, контекст использования | Покрытие сценариев |

## Логотип сайта

- Загрузка: **Налаштування → Загальні налаштування → Логотипи**
- Оптимально: PNG в большом разрешении (платформа сжимает автоматически)
- Отдельные поля:
  - **Основной** — для шапки десктопа
  - **Мобильный** — горизонтальный вариант (или скрыть, если близок к квадрату)
  - **Футер** — белый на прозрачном
  - **Для печати** — черно-белый

📄 [Загрузка логотипа](https://help.horoshop.ua/ru/articles/1913435-загрузка-логотипа)

## Что аудит может детектить через API

✅ **Возможно через `catalog/export`:**
- Кол-во фото (`images.length + gallery_common.length`)
- Дубли URL'ов между товарами
- Наличие `gallery_360`

⚠️ **Требует HEAD-запросов к URL:**
- Размер файла (Content-Length)
- HTTP статус (404 = битый)
- MIME-тип (Content-Type)

❌ **Невозможно через API:**
- Реальное разрешение изображения (нужен GET + декодирование)
- Качество (Image quality score)
- Соответствие фото товару (визуальный анализ)
- Наличие водяного знака

## Что чинить

| Что | Как | Через что |
|---|---|---|
| Добавить фото | Через `catalog/import` с `images.links[]` или FTP | API |
| Удалить лишние | `images.override: true` + новый список | API |
| Очистить галерею 360 | `gallery_360.removeAll: true` | API |
| Заменить порядок | `images.override: true` + новый список в нужном порядке | API |
| Включить/выключить водяной знак | Админка | Только UI |
| Изменить главное фото | Первый URL в `images.links[]` | API |
