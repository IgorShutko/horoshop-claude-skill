## 🟢 Що виправляється через API


### 1. Минулі акції (`countdown_end_time`) — 127 товарів

**Чому важливо:** На сторінці товара показується мертвий таймер або від'ємні значення. Підриває довіру.

**Як виправити:** Запустити `apply_fixes.py --fix countdown` — обнулить дату або продовжити.


### 2. Порожній `mod_title` — 77 модифікацій

**Чому важливо:** У селекторі модифікацій користувач не бачить осмисленого імені (Двоспальний, Євро тощо).

**Як виправити:** Запустити `apply_fixes.py --fix mod-title` — заповнить з ключової характеристики (rozmr/розмір).


### 3. `discount=0` при реальній знижці — 44 товарів

**Чому важливо:** Хорошоп показує стікер -X% на основі поля `discount`. Якщо 0 — стікер прихований.

**Як виправити:** `apply_fixes.py --fix discount` — порахує `(old-price)/old*100` і запише.


### 4. Порожні SEO-поля — до 1 товарів

**Чому важливо:** SEO-шаблон дає дефолт, але унікальні мета-теги дають контроль над сніпетом і вищий CTR.

**Як виправити:** `apply_fixes.py --fix seo --preview-only` → переглянути → `--fix seo` записати.


### 5. Відсутній MPN — 44 товарів

**Чому важливо:** Google Shopping/Rozetka/Facebook фіди вимагають MPN або GTIN. Без них модерація відхиляє.

**Як виправити:** `apply_fixes.py --fix mpn --prefix XX` — генерує `XX-{article}` для всіх.


### 6. Дублікати description — 6 груп

**Чому важливо:** Google пеналізує дублі канонікалізацією → одна сторінка в індексі, інші втрачаються.

**Як виправити:** `apply_fixes.py --fix dup-desc` — переписує під унікальні характеристики (превью обов'язкове).


### 7. Оплата частинами вимкнена — 44 товарів

**Чому важливо:** Для середнього чека ≥500 грн розстрочка — стандартний канал конверсії в UA.

**Як виправити:** `apply_fixes.py --fix installments` — увімкне Privat + Monobank.


### 8. Стікер «Распродажа» відсутній — 43 товарів зі знижкою

**Чому важливо:** Стікер — головний візуальний CTA в каталозі. Без нього скидка менш помітна.

**Як виправити:** `apply_fixes.py --fix sticker-sale --sticker-name Распродажа` — додасть в `icons[]`.


### 9. Inline-стилі в описах — 42 товарів

**Чому важливо:** HTML захаращений `style="..."` атрибутами. Не критично, але сповільнює рендер і конфліктує з темою.

**Як виправити:** `apply_fixes.py --fix inline-styles --preview-only` → переглянути → запустити без `--preview-only`.


### 10. Cross-sell не налаштовано — accessories/alt_parent у 43 товарів

**Чому важливо:** Втрачений AOV (без блоку «з цим товаром купують») і внутрішня перелінковка (без альтернативних розділів типу «Хіти»).

**Як виправити:** `apply_fixes.py --fix cross-sell --interactive` — потрібне обговорення стратегії що до чого прив'язувати.


## 🟡 Що виправляється тільки в адмінці


### A1. Довгі title у 15 категорій (>70 симв)

**Чому важливо:** Google ріже title у видачі до ~580 px (~65 симв кирилиці). Хвіст шаблону губиться.

**Де правити:** **Маркетинг → SEO → SEO шаблони → Категорії** — скоротити шаблон до ~50-60 симв.

**Приклади:**
- `/category-color-1/`
- `/category-size-l/`
- `/seasonal-collection/`
- `/discount-collection/`
- `/new-arrivals/`


### B. Інфо-сторінки без description (2 шт)

**Чому важливо:** Без description Google генерує сниппет з тексту — зазвичай невдало.

**Де правити:** **Сторінки сайту → Інформаційні сторінки → [сторінка] → SEO**

**Приклади:**
- `/privacypolicy/`
- `/care-instructions/`


### C. Кілька `<h1>` на сторінці (1 шт)

**Чому важливо:** Розмиває семантику для Google. Має бути один h1 на сторінку.

**Де правити:** Перевір SEO-текст і шаблон сторінки — скоріш за все продубльовано.

**Приклади:**
- `/privacypolicy/`


### D. Головна без `<h1>`

**Чому важливо:** h1 — головний текстовий сигнал теми. Без нього головна втрачає вагу за брендом і основною категорією.

**Де правити:** **Редактор дизайну → Головна → блок із заголовком**


### E. Приховані товари (16 шт)

**Чому важливо:** Сміття в API. Якщо колись були відкриті — можуть лишитися в індексі Google як 404.

**Де правити:** **Каталог → Товар** — повернути в продаж, перевести в архів або видалити.


### F. Порожній УКТ ВЕД (44 товарів)

**Чому важливо:** Не для SEO. Потрібно для ПРРО Checkbox (чек), імпорту/експорту, фідів. Через API не редагується.

**Де правити:** **Каталог → Товар → УКТ ВЕД** (вручну або CSV-імпортом).


### G. Категорії без SEO-тексту (1 шт)

**Чому важливо:** SEO-текст — основний контент для ранжування за комерційними запитами категорії.

**Де правити:** **Каталог → Категорія → SEO-текст** — додати блок 800-2000 симв з h2/h3.


## 🚫 Що НЕ змінюємо

- robots.txt — стандартний для платформи
- Sitemap.xml — генерується автоматично
- Schema/microdata — реалізована платформою
- URL-формули, hreflang, canonical — налаштовано платформою
- Slug з `/{id}` в кінці — це формат Хорошопа
