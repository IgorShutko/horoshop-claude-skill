# Инструкция для клиента — создание API-доступа на Хорошопе

Покажи пользователю **именно этот текст** (можно адаптировать под форматирование платформы), когда:
- Не предоставлены креды (логин/пароль)
- Auth-проверка вернула `User with such username/password not found`

---

## 📋 Создать API-доступ для аудита

Чтобы я мог подключиться к магазину и провести аудит, нужно завести API-пользователя.

### Шаги:

1. Зайди в админ-панель: **https://<твой-домен>/admin**
2. Перейди: **Налаштування → Користувачі → Додати користувача**
3. Заполни:
   - **Логін:** `api`
   - **Пароль:** любой надёжный (например `ApiSecure2026!`)
   - **Роль:** `Owner` (нужны полные права для чтения каталога и обновления товаров)
   - **Email:** любой технический (необязательно)
4. Сохрани

### Что отправить мне:

```
Домен: <example.com.ua>
Логин: api
Пароль: <тот, что задал>
```

> ⚠️ Используй роль `Owner` — иначе API не сможет обновлять товары при выполнении фиксов. Если боишься давать полный доступ — после аудита можно деактивировать пользователя.

## Альтернативно — если уже есть API-пользователь

Если в магазине уже создан API-юзер с другими данными — пришли:
- логин
- пароль
- (или подтверди что роль `Owner`)

Я подключусь.

---

## Технические детали (для info)

- API endpoint: `https://<DOMAIN>/api/auth/`
- Метод: `POST` с JSON `{"login":"...","password":"..."}`
- Возвращает токен на 600 секунд
- Все последующие запросы используют этот токен
- Токен пересоздаётся автоматически при истечении
