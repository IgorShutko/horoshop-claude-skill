# Промпт-рецепты для Claude (генерация контента)

Этот файл — для Claude в основном чате. Когда пользователь говорит «сгенерируй описания на основе gaps.json», следуй этим паттернам.

## Общий workflow генерации

1. Прочитай `gaps.json` — список товаров с пустыми полями
2. Прочитай `references/content_templates.md` — структура и длины
3. Уточни у пользователя если непонятно (обычно 1-2 вопроса):
   - Какой тон? (формальный / разговорный / премиум / эконом)
   - Что особенное у бренда? (свой пошив, доставка 1 день, гарантия 2 года)
   - Должен ли быть CTA? Если да — какой стандартный?
4. Сгенерируй для каждого товара поля из `gaps`
5. Сохрани в `proposed_content.json`
6. Сообщи пользователю: «Готово, проверь через `apply_content.py --preview-only`»

## Что использовать из контекста товара

Из каждого item в `gaps.json` ты получаешь:
- `title` — название (главный источник keyword'ов)
- `brand` — бренд магазина
- `category` — категория (для тональности)
- `price`, `price_old` — для CTA («від X грн» если price_old > price)
- `characteristics` — словарь реальных характеристик. **ТОЛЬКО они — источник правды о товаре.**
- `existing_description` (если есть фрагмент) — для подражания стилю если description частично заполнен
- `existing_short_description`, `existing_marketplace_description` — то же

## Как генерировать `description`

Шаблон в `content_templates.md`. Правила:

1. **Вступление** (1-2 предложения):
   - Что это (категория + ключевая характеристика из `title` или `characteristics`)
   - Для кого (если category намекает: дитячі / для подружжя / etc.)

2. **Секция «Особливості»** (5 буллетов, h2 + ul):
   - Каждый буллет = факт из `characteristics` + выгода для покупателя
   - Пример: «Мікросатин 120 г/м² — ніжний на дотик і не мнеться»
   - **Не выдумывай** характеристики которых нет

3. **Секция «Характеристики»** (h2 + ul):
   - Дублируй из `characteristics` в читабельной форме
   - `materal` → «Матеріал», `kranaVirobnik` → «Країна виробництва», `kolr` → «Колір», `rozmr` → «Розмір», `shlnst` → «Щільність»
   - Если ключи на русском транслите — мапь в украинский в выводе

4. **Секция «Догляд»** (h2 + p):
   - Если в `characteristics` есть `rekomendacjaPoDogljadu` или `careInstructions` — переписать в виде советов
   - Если нет — пропусти эту секцию

5. **CTA** (последний параграф):
   - Универсальный: «Замовте з доставкою по Україні 1-2 дні»
   - Кастомный: если пользователь дал brand promise — использовать

## Как генерировать `short_description`

- Plain text, 100-200 символов
- Один яркий факт + одно преимущество
- Шаблон: `[Категория] [материал/особенность]. [Главное преимущество]. [Бренд] / [география].`

Пример:
```
title: «Рюкзак спортивний 25 л водонепроникний»
characteristics: {"material": "Поліестер 600D", "country": "Україна", "volume": "25 л"}
brand: "MyBrand"
price: 899

→ short: «Спортивний рюкзак 25 л з водонепроникного поліестеру 600D. Тримає форму, м'які лямки. Виробництво України.»
(112 симв)
```

## Как генерировать `marketplace_description`

- Plain text, 50-150 символов (жёсткий лимит для feeds)
- Конкретный факт + бренд / география
- Без HTML, без переносов

Пример:
```
title: «Куртка зимова жіноча Aurora»
characteristics: {"material": "Поліестер 100%", "padding": "Холлофайбер", "country": "Україна"}
brand: "MyBrand"

→ marketplace: «Жіноча зимова куртка з холлофайбером від MyBrand. Поліестер, водовідштовхувальна. Доставка 1-2 дні.»
(106 симв)
```

## Чего избегать (AI-стоп-слоп паттерны)

❌ **Заглушки и пустословы:**
- «является», «представляет собой»
- «при этом», «по сути», «в целом»
- «буквально», «крайне», «весьма»
- «не просто [Х], а целый [Y]»
- «Хотите [X]? Тогда вам сюда.»

❌ **Маркетинг-вода:**
- «высочайшее качество», «непревзойдённый», «уникальный»
- «специально для вас», «именно для вашего комфорта»
- «инновационный», «передовой»

❌ **Технические перечисления без выгоды:**
- «120 г/м²» (без объяснения почему это важно)
- → лучше: «120 г/м² — оптимальна щільність, не просвічує»

❌ **Списки прилагательных:**
- «качественный, надёжный, удобный, практичный»
- → один точный факт лучше 4 шаблонов

## Мульти-языки

- Магазин обычно работает на одном языке (`HOROSHOP_LANG`, по умолчанию `ua`)
- Если магазин двуязычный — генерируй сразу для обоих:
  ```json
  {
    "article": "1234",
    "description": {"ua": "...", "ru": "..."}
  }
  ```
  (вместо плоской строки)

## Защита от галлюцинаций

- ❌ Не выдумывай страну производства (`kranaVirobnik`)
- ❌ Не выдумывай состав (`materal`)
- ❌ Не указывай конкретные сроки гарантии если их нет в данных
- ❌ Не упоминай скидку «-30%» если price_old не указан или равен price

✅ Всегда проверяй: каждый факт в твоём тексте → есть в `characteristics` или известных полях товара?

## Формат `proposed_content.json`

```json
[
  {
    "article": "1234",
    "description": "<p>...</p><h2>Особливості</h2>...",
    "short_description": "...",
    "marketplace_description": "..."
  },
  {
    "article": "1235",
    "description": "...",
    "short_description": "..."
  }
]
```

- Включай только те поля которые в `gaps` для этого товара (не пиши пустые)
- `description` — HTML строка
- `short_description` и `marketplace_description` — plain text
- Для двуязычных магазинов — мультиязычные dict'ы
