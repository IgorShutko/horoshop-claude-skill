# Шаблоны контента для карточек товара

## `description` — основное описание (HTML)

**Длина:** 800-1500 символов чистого текста (без HTML-тегов)
**Формат:** HTML с структурой
**Минимум:** 1 параграф вступления + 2 секции h2

### Рекомендуемая структура

```html
<p>[1-2 предложения вступления — что это, для кого, главное преимущество]</p>

<h2>Особливості</h2>
<ul>
  <li>[3-5 ключевых характеристик товара, привязанных к выгоде для покупателя]</li>
</ul>

<h2>Характеристики</h2>
<ul>
  <li><strong>Матеріал:</strong> [из characteristics]</li>
  <li><strong>Розмір:</strong> [из characteristics]</li>
  <li><strong>Виробник:</strong> [из brand]</li>
</ul>

<h2>Як використовувати / Догляд</h2>
<p>[Конкретные инструкции по уходу/использованию, если есть в characteristics.rekomendacjaPoDogljadu]</p>
```

### Что включать

- ✅ Только характеристики которые **есть в данных** товара
- ✅ Конкретные числа (плотность, вес, размер) если они в `characteristics`
- ✅ Один CTA в конце («Замовте сьогодні», «Доставка по Україні 1-2 дні»)
- ✅ Ключевые слова из `title` (натурально, не вспомогательно)

### Чего избегать

- ❌ Выдумывать характеристики которых нет в данных
- ❌ Маркетинг-стопа: «качественный», «лучший», «уникальный», «инновационный»
- ❌ Шаблонные фразы которые подходят к любому товару
- ❌ Эмодзи в основном тексте описания (опционально в h2 — норма)
- ❌ Длинные параграфы без подзаголовков

## `short_description` — краткое описание

**Длина:** 100-200 символов
**Формат:** plain text, без HTML
**Назначение:** показывается в листинге каталога, превью, в фидах

### Что включать

- 1-2 предложения
- Главное преимущество товара
- Конкретный факт (плотность, материал, страна)

### Примеры

✅ Хорошо:
```
Зимова куртка з мембраною 5000 мм. Тепла до -20°C, м'який поліестер. Виробництво України.
```
(89 символов, плотный, конкретный, бренд+факты)

❌ Плохо:
```
Качественный комплект постельного белья высочайшего качества, который порадует вас своими уникальными свойствами и долговечностью.
```
(шаблон, нет фактов, AI-вода)

## `marketplace_description` — описание для фидов

**Длина:** 50-150 символов
**Формат:** plain text, без HTML, без переносов строк
**Назначение:** Google Shopping, Facebook Feed, Rozetka. Жёсткие требования к длине у Google (155 симв max в snippet).

### Что включать

- Конкретный факт + USP в одной фразе
- Бренд если есть место

### Примеры

✅ Хорошо (89 симв):
```
Куртка зимова жіноча, мембрана 5000 мм. Тепла до -20°C, водовідштовхувальна. Доставка 1-2 дні.
```

✅ Хорошо (74 симв):
```
Дитяча піжама 100% бавовна. Розмір 110-140. Без хімії. Виробництво України.
```

❌ Плохо (>200 симв):
```
Этот великолепный комплект постельного белья изготовлен из высококачественного микросатина с плотностью 120 г/м² и обладает отличными антиаллергенными свойствами...
```

## Тональность по нишам

| Ниша | Тон | Особенность |
|---|---|---|
| Текстиль / дом | Тёплый, забота | Подчёркивать «комфорт», «затишок», «якість сну» |
| Одежда | Стиль, тренды | Подчёркивать актуальность, посадку, ткань |
| Электроника | Технический | Спецификации, характеристики на первом месте |
| Детские товары | Заботливый, безопасность | Подчёркивать гипоаллергенность, сертификаты |
| B2B / опт | Деловой | Объёмы, скидки, срок поставки, документы |
| Косметика | Эмоциональный | Состав, эффект, сертификации, тестировано |

## Соответствие brand voice

При генерации учитывай **тон от пользователя** (передаётся при запуске скилла):
- **Формальный** — «Ви», без сокращений, нейтральный
- **Разговорный** — «ти» / «ви», эмодзи допустимы в h2, можно лёгкий юмор
- **Премиум** — длинные предложения, акцент на качество и эксклюзивность
- **Эконом** — короткие фразы, акцент на цену и доступность
