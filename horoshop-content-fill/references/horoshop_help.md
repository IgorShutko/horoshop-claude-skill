# Справка Хорошопа — текстовый контент карточек

Выжимка из официальной документации `help.horoshop.ua`, релевантная заполнению пустых описаний.

---

## Текстовые поля товара (что заполняем)

### `description.<lang>` — основное описание

- HTML-формат (поддерживает `<p>`, `<ul>`, `<ol>`, `<li>`, `<table>`, `<a>`, `<strong>`, `<em>`, `<h2>`, `<h3>`, `<img>`)
- Где видно: страница товара, между галереей и характеристиками
- Лимит best-practice: 800–2500 символов
- **Inline `style=...` Хорошоп переопределяет** — стили задавать через CSS темы (Сайт → Дизайн → Редактор кода) или не делать вообще

### `short_description.<lang>` — короткое описание

- Простой текст или минимальный HTML
- Где видно: под главным фото на странице товара (выше галереи), в листинге каталога (если включено в настройках)
- Лимит best-practice: 100–250 символов
- Должно отвечать «Зачем мне это покупать?» в 2-3 фактах

### `marketplace_description.<lang>` — описание для маркетплейсов

- Простой текст без HTML
- Где видно: **только в товарных фидах** (Rozetka Feed, Google Merchant Feed, Facebook Catalog Feed)
- Лимит best-practice: 800–1500 символов
- Должно содержать: материал, размер, страна, особенности использования
- Если пусто — фид использует `description` (часто перегруженное с HTML → плохо для маркетплейса)

### `seo_title`, `seo_description`, `seo_keywords`, `h1_title`

- См. `~/.claude/skills/horoshop-text-quality/references/horoshop_help.md` для детальных ограничений
- Заполняются через тот же `catalog/import`

📄 [API: Каталог](https://help.horoshop.ua/ru/articles/3960898-api)

## Multilingual

### Через API
```json
{
  "description": {
    "ua": "<p>Текст українською</p>",
    "ru": "<p>Текст на русском</p>"
  }
}
```

Или одной строкой во все языки:
```json
{
  "description": "<p>Single text для всех языков</p>"
}
```

### Какие языки поддерживаются
- `ua`, `ru`, `en`, `pl`, и др. — зависит от настройки магазина
- Список активных языков: **Налаштування → Мови сайту**

📄 [Языки на сайте](https://help.horoshop.ua/ru/articles/1703586-языки-на-сайте)

## SEO шаблоны (когда лучше шаблон, когда — индивидуально)

### Когда хватит шаблона
- Каталог из 1000+ товаров — заполнить вручную нереально
- Однотипные товары (например, варианты комплекта)
- Категории второго уровня

**Шаблон ставится в:** Маркетинг → SEO → SEO шаблоны → +Додати

### Когда нужно индивидуально
- Топ-20 товаров (A-группа из ABC-анализа) — заслуживают вручную написанных SEO
- Лендинги категорий с большим SEO-трафиком

### Как они комбинируются
- Если поле в товаре заполнено вручную — оно **переопределяет** шаблон
- Если поле в товаре пустое — Хорошоп подставляет результат шаблона в HTML
- В БД (через `catalog/export`) пустые поля остаются пустыми (шаблон применяется только в HTML рендере)

📄 [SEO шаблоны](https://help.horoshop.ua/ru/articles/1703563-seo-шаблоны)

## Структура хорошего описания (best practice)

```html
<p>Короткое 1-2 предложения — что это и для кого.</p>

<h3>Особенности</h3>
<ul>
  <li>Свойство 1 → польза для покупателя</li>
  <li>Свойство 2 → польза для покупателя</li>
  <li>Свойство 3 → польза для покупателя</li>
</ul>

<h3>Технические характеристики</h3>
<table>
  <tr><td>Материал</td><td>Бавовна 100%</td></tr>
  <tr><td>Розмір</td><td>2-спальний (180×220 см)</td></tr>
  <tr><td>Виробник</td><td>Україна</td></tr>
</table>

<h3>Доставка та оплата</h3>
<p>Доставка по Україні Новою Поштою 1-2 дня. Оплата: готівкою при отриманні, картою онлайн.</p>

<h3>Гарантія</h3>
<p>14 днів на повернення без пояснення причин.</p>
```

### Чего избегать в `description`
- Inline-стили (`style="..."`)
- `<script>` (удаляется)
- Блоки рекламы (отвлекает от покупки)
- Дублирование с `short_description`
- Маркетинг-вода («непревзойдённое качество», «лидер рынка») — см. `~/.claude/skills/horoshop-text-quality/references/patterns.md`

## Через API: пакетная загрузка

### `catalog/import` (POST)
```json
{
  "token": "...",
  "products": [
    {
      "article": "ABC-001",
      "description": {
        "ua": "<p>Текст</p>",
        "ru": "<p>Текст</p>"
      },
      "short_description": {
        "ua": "Короткий опис",
        "ru": "Короткое описание"
      }
    }
  ]
}
```

### Лимит — 50 товаров на батч
- Хорошоп не документирует жёсткий лимит, но 50 — безопасное значение
- 100+ может вызвать timeout

### Коды результата
- `0` — товар обновлён
- `11` — поле не активно в шаблоне данных (см. ниже)

---

## Code 11 — поле не в шаблоне

### Когда возникает
При попытке записать через `catalog/import` поле, которое **выключено** в шаблоне данных магазина.

Чаще всего: `marketplace_description` или v4-only поля (`installments_payment`, `monobank_installments_payment`).

### Как починить
**Налаштування → Система → Каталог → Шаблон даних → активувати потрібне поле**

### Откуда узнать что в шаблоне
- Включить поле в админке вручную
- Или прогнать пробный `catalog/export` — если поле возвращается с пустым значением, оно в шаблоне; если не возвращается вовсе — не в шаблоне

📄 [Шаблоны товаров](https://help.horoshop.ua/ru/articles/3960878-создание-и-настройка-шаблонов-товаров)

## Workflow генерации (через Claude в чате)

### Шаги
1. `find_gaps.py` → находит товары с пустыми полями → `gaps.json`
2. **Claude в чате:**
   - Читает `gaps.json` + `references/content_templates.md`
   - Читает `references/prompt_recipes.md` для тоновки бренда
   - Генерирует контент → пишет в `proposed_content.json`
3. `apply_content.py --preview-only` → показывает что запишет
4. `apply_content.py` → пакетно через `catalog/import`

### Что Claude должен учесть
- Бренд-тон (посмотреть существующие описания топ-товаров — взять общий стиль)
- Категория товара (постельное белье ≠ электроника по тону)
- Целевую аудиторию магазина (B2C / B2B)
- Уже существующие описания других товаров (не делать копию, но соблюдать общий стиль)

## Что НЕ заполняем через content-fill

❌ `seo_title`, `seo_description` — эту работу обычно делает SEO-специалист с учётом ключевых слов
❌ Характеристики (`material`, `country`, ...) — это работа `horoshop-content-fill --fields characteristics` (отдельный режим если нужен) или ручной импорт
❌ Цены (`price`, `price_old`) — никогда автоматически
❌ Изображения — отдельная задача (`horoshop-photo-audit` для аудита)
